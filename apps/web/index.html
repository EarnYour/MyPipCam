Frequently asked questions

What is MyPipCam?

A free, open-source toolkit for screen recording with a live camera picture-in-picture: Chrome extension for capture and editing, plus a macOS always-on-top camera companion.

Is MyPipCam a Loom alternative?

It’s inspired by picture-in-picture screen-recording workflows — local-first and open source. It is not affiliated with Loom; “Loom-style” is descriptive only.

Where are my recordings stored?

On your device by default (browser storage or a folder you choose). Optional Drive upload and OpenAI transcription only run when you connect those services. See the Privacy Policy.

How do I install MyPipCam?

Get the extension and macOS app from GitHub and follow the README for build and install steps.
