Google Drive, shared folders & view tracking

Connect Google once in Library Settings. Your clips can live in Drive, stay on a local folder both apps use, and ship as share links that report views back to you.

  • Connect Google Drive

    In the Chrome Library → Settings → Connect Google. MyPipCam creates a MyPipCam folder in your Drive (drive.file scope only). The same Google account on other computers can list and play uploaded clips.

  • Shared local library folder

    Pick the same folder (for example ~/Movies/MyPipCam) in Chrome and in the Mac app. Both sides read and write the same on-disk library so recordings stay in sync offline.

  • Share links that track views

    Share from the Library to copy a mypipcam.earnyour.com/w/… watch link. Viewers open that page (Drive video embedded); you see view count and last viewed in the Library — Loom-style feedback without a SaaS vault.

  • You stay in control

    Drive and OpenAI only run after you connect them. Disconnect anytime. See the Privacy Policy for what stays on-device vs. optional cloud.

Frequently asked questions

What is MyPipCam?

A free, open-source toolkit for screen recording with a live camera picture-in-picture: Chrome extension for capture and editing, a macOS always-on-top camera companion, optional Google Drive sync, and share links with view tracking.

Is MyPipCam a Loom alternative?

It’s inspired by picture-in-picture screen-recording workflows — local-first and open source, with Drive + view-tracked share links when you want cloud. It is not affiliated with Loom; “Loom-style” is descriptive only.

How does Google Drive connection work?

Open Library → Settings → Connect Google and finish the Google sign-in. Uploads go to a MyPipCam folder in your Drive. Use the same Google account in Chrome on another computer to see those uploads. You can still keep a local folder for Mac + Chrome offline.

Do shared links show view counts?

Yes. Library → Share copies a https://mypipcam.earnyour.com/w/… link. Each open counts as a view; your Library shows how many times it was viewed and when it was last opened. The file itself stays in your Google Drive.

Where are my recordings stored?

On your device by default (browser storage or a folder you choose). Optional Drive upload and OpenAI transcription only run when you connect those services. See the Privacy Policy.

How do I install MyPipCam?

Get the extension and macOS app from GitHub and follow the README. After install, connect Drive from Library → Settings if you want cloud sync and share views.
